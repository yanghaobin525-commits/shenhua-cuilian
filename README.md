# 神话·淬炼

中国神话单机动作 Roguelike。v10 起为孙悟空单人闯关（五人模式代码保留）。横屏触控设计；真实 iPad Safari 仍待硬件验收。

## v10 孙悟空单人 · 固定斜俯视 · 房间制 · 狼王式首领

固定斜俯视镜头（去掉旋转），水墨山岛。五间房：肃清一间三选一祝福，第五间为首领白啸狰王（蓄力扑咬 / 跃扑落地扬尘 / 裂爪 / 二阶段召妖）。悟空三段连招逐段夸张：轻击快戳 → 普通挥扫 → 跃起重砸，每段有自己的关键姿势、月牙轨迹光、伤害和顿帧，之后循环；闪避带无敌帧，三个技能，目标锁定防空 A。主角不再显示地面红圈，敌方攻击保留地面预警。单人结算后可用新种子再战。详见 [v10 说明](V10-RELEASE.md)。`node test/v10-solo-browser.cjs` 为 1024×600 触屏模拟完整流程测试（不是真机）。

## v9 平台校正 · 三式连招 · 金牌结算

平台改为无剪切的固定俯仰圆形石台，小块石纹和水平椭圆阵环保持各角度的平整线索；道具缩小，镜头倍率2.2（v8为1.55）。按住普攻连续三式，收招末尾点按也可衔接；八武器各有三条局部手/躯干/武器轨迹，超时、受击打断、换武器、倒地清空连段。伤害仍为原普攻值，每段仅释放一次。狰新增可躲扑击，普通怪与九婴有不同局部身体动作；不是完整骨骼动画。四张金色肖像奖牌与总MVP使用真实贡献，详细战绩折叠。见 [v9说明](V9-RELEASE.md)。

`npm run test:v9` 包含动态视频夹具、短平板视口、完整循环与八人/64换武器回归。视频交付供人工动态评审；自动测量与静态Read不等同于看过视频。

## v8 群山悬岛 · 循环试炼

选人后打开「开局设置」：怪物血量 0.25–5 倍、难度 0.5–3 倍、关卡 1–10 轮。每轮四波，末波九婴；每波三选一真实祝福，全队共享，仅本局有效。有限轮次全部完成即通关，全队倒下即失败。设置保留，再开换新种子并清空本局构筑/战绩。

倒地队友附近会出现「按住救助」（键盘 R）；读条完成才计救援，AI 也能救人。波后系统复苏不算救助。结算有全队真实账本、四项独立最佳与透明规则 MVP，没有玩家优待。详见 [v8 功能、证据与限制](V8-RELEASE.md)。

`npm test` 为纯规则/渲染契约测试；`npm run test:v8` 为生产资产门禁、实际 Chromium 触控流程、八人/64换武器、双尺寸投影遮挡、完整360度转镜头测试。先启动本地 HTTP 服务于 8787。`test:v6/v7` 已转接兼容的现行回归，旧版单脚本保留为历史参考。GitHub Actions 仅跑确定性 Node 契约；真实浏览器/资产验收仍为发布前显式步骤。

原创粗墨山海悬崖平台、远中近云山差速视差。人物直立的2.5D斜视，默认镜头倍率2.2（v8为1.55）；右上↶/↷或Q/E每次45度转视角。左侧摇杆始终按屏幕方向移动，右下按住普攻，武器单主动按钮显示冷却。波次间走近武器即可拾取替换。

英雄只有被动天赋，普攻与技能由当前武器决定。数值与中文说明见 config.js。

Phaser 3.90.0 本地打包，MIT 许可证见 lib/PHASER-LICENSE.md。其他代码及游戏图像为本项目原创。无付费、无个人信息收集。


## approved-v6 接入与验收

- 选角使用 `assets/selection-v6`，源文件追溯在其 manifest；哪吒沿用获批原稿，悟空/八戒沿用 v5，另五人 v6。只去纸底，不用于战斗。
- 战斗专用 `assets/approved-v6/{hero}/{front,back,side,weapon}.png`。512 方形、透明、脚底约 0.92；目录由美术维护。
- 每人 `manifest.json` 支持下面的标准结构（全部坐标 normalized）：

```json
{"footY":0.92,"sideFaces":"right","views":{"front":{"handAnchor":{"x":0.3,"y":0.55}},"back":{"handAnchor":{"x":0.7,"y":0.55}},"side":{"handAnchor":{"x":0.65,"y":0.55}}},"weapon":{"grip":{"x":0.5,"y":0.7},"rotation":0}}
```

也兼容顶层 `handAnchor: {front,back,side}`；必须提供真实握点，不能用默认假坐标糊弄。

- `combat-art.js` 是图像局部网格形变，**不是骨骼分件**：呼吸、左右腿交替、手臂区域普攻挥动/施法上举；独立武器跟随同一手锚，背向压在身体后面，正面以空手真实像素盖过握杆。视觉表现及手机性能仍须真实素材测评。
- 保留五人 AI、波次/Boss、碰撞伤害系统；AI 与玩家均只用武器 skill1。UI 是红心血环 + 武器/衣/鞋三个槽；衣鞋显示相应祝福强化层级并真实影响生命/减伤/移速，但尚无独立衣鞋道具替换。
- Boot 对缺失/缺握点素材直接显示阻塞，不降级成旧图。

### 已知边界

- 战斗素材是新绘的空手三向图，实际约 2.2–2.5 头身；与选角立绘用途不同。局部网格动画不是独立骨骼、不是逐帧重绘。
- 正背图的持手解剖侧别有个别不连续，按各视图真实手心挂点绘制；不承诺完整三维旋转或左右非对称装备始终同侧。
- 接入视觉核对修正了二郎神落在透明像素的武器握点，以及八戒/沙僧/白龙实际左向侧图被误标 right、手点偏离掌心的问题。
- 八戒战斗用耙偏钢灰，非选角青绿色；极小尺寸下毛发布线与细纹会合并。v7清理大片纸底与封闭孔洞；v8二检40张中修正26张、14张保持原样，清理发髻白带和识别到的孤立浅点。固有白发/肤色/高光保留，不承诺逐像素完美。
- 衣鞋槽显示本局祝福强化；换武器与单主动同步，但衣鞋独立换装与新外观尚未实现。
- 自动触屏检查运行在 headless Chromium 的 iPad 横屏尺寸/多触点环境，不等同于真实 iPad Safari 硬件验收。

唐僧最终局部修正：侧面朝右、袈裟远侧左肩，锡杖九环已补成 3+3+3；接入握点改为 (318,224)/512。橙袍仍有轻微金格残留。


## v7 历史基线：斜视 2.5D 封印石院

`arena-view.js` 将世界坐标投影为 `sx=marginX+x+shear*y`、`sy=marginY+y*yScale-z`；相机与地面点击使用同一逆变换，HUD 保持屏幕坐标。参数集中在 `config.js:view25d`。角色与武器是脚底对齐的直立 billboard，不压扁人物；场边立柱、石灯、门楼、枯树有高度与前后面，以世界脚 Y 与人物共同排序。石板、阵纹和高物均为原创程序绘制，不使用商业游戏贴图。边界立物有世界坐标碰撞。

地面预警、技能扇面、圆环、影子、掉落与飞行物采用同一投影。投射物世界 XY 与显示高度 Z 分离，碰撞只在世界平面计算；粒子发射位置和速度也进行投影。此版本保留原有 AI、波次、武器、伤害、声音和局部网格动作，不宣称已复现其他游戏。
